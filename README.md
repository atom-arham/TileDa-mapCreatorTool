# TileDa - Tile-Based Map Creation Tool

Features:
- Paint Brush
- Fill Bucket
- Area Fill
- Adjustable Grid
- Zoom In and Out feature
- Export as PNG
- Asset Manager

Upcoming Features:
- Export as JSON
- Dark Mode

How To Run:
- Just Run the .Jar file
